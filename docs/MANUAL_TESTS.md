# V0.1 手动集成测试

这些测试需要真实 Chrome/Chromium、真实 DeepSeek 会话和一个仅有读取权限的 GitHub Token。自动化单元测试不替代以下网页 DOM 验收。

| 编号 | 操作 | 期望 |
| --- | --- | --- |
| 1 | 构建并在 `chrome://extensions` 加载 `dist` | 扩展无 Manifest/Service Worker 错误 |
| 2 | 打开 `chat.deepseek.com`，点击扩展图标 | 侧边栏显示“页面已识别”；找不到输入框时可刷新状态 |
| 3 | 在输入框键入 `已有提示词`，侧边栏连接 GitHub | 显示 GitHub 用户名，不显示 Token |
| 4 | 选择仓库和默认分支，进入两层目录 | 目录与文件分开排序，面板不崩溃 |
| 5 | 选择一个 UTF-8 源文件并展开预览 | 显示仓库、ref、路径、语言 fence 和完整原文 |
| 6 | 再从另一目录选择一个文件 | 文件计数、字符估算和预览同步更新 |
| 7 | 点击“附加到 DeepSeek” | 输入框出现 Markdown 上下文，原提示词仍在前面 |
| 8 | 检查 DeepSeek 页面 | 没有自动点击发送；用户可继续编辑 |
| 9 | 刷新页面或切换会话后点击刷新 | 适配器重新寻找编辑器；找不到时显示可理解状态 |
| 10 | 选择 PNG/锁定权限文件/无效 Token | 显示错误，既有选择不被清空，Token 不出现在错误文字中 |
| 11 | 在窄窗口约 320px 宽打开侧边栏 | 没有横向溢出，文件名和预览可滚动 |
| 12 | 在仓库根目录点击“加入目录树” | 待附加上下文出现目录树条目，预览包含 DIR/FILE 路径 |
| 13 | 搜索 `auth` 或 `token` | 显示代码搜索结果，点击结果后文件加入上下文 |
| 14 | 同时加入目录树和搜索结果文件，再点击附加 | DeepSeek 输入框同时出现仓库结构和文件内容，且不自动发送 |
| 15 | 选择两个不同分支并点击“加载 Diff” | 显示变更文件、增删统计和文件勾选框 |
| 16 | 取消部分 Diff 文件后点击“Add Diff to Context” | 只附加勾选的 Diff 文件，预览包含 Base、Head、patch 和变更清单 |
| 17 | 选择包含二进制或超大文件的分支比较 | 无 patch 文件显示 `Patch omitted by GitHub`，不会因 patch 缺失崩溃 |
| 18 | Diff 请求返回前切换仓库或分支 | 旧 Diff 不会显示，也不会进入当前上下文 |
